scapy.layers.tftp

TFTP (Trivial File Transfer Protocol).

This provides TFTP implementation and 4 small automata:

  • TFTP_read: read a remote file

  • TFTP_RRQ_server: server that answers to read requests

  • TFTP_write: write a remote file

  • TFTP_WRQ_server: server than accepts write requests

TFTP automaton to serve local files

You can’t use ‘store’ and ‘dir’ at the same time.

Parameters:

  • store – (optional) a dictionary that contains the file data, like {“thefile”: b”data”}.

  • dir – (optional) a folder that contains the data file data.

  • joker – (optional) data to return when no file/data is found.

  • ip – (optional) the local IP to listen on.

  • sport – (optional) the local port (by default: random)

  • serve_one – (optional) close after serving one client (default: False)
