scapy.layers.tls.crypto.groups

This is a register for DH groups from RFC 3526 and RFC 4306. At this time the groups from RFC 7919 have not been registered by openssl, thus they cannot be imported from the cryptography library.

We also provide TLS identifiers for these DH groups and also the ECDH groups. (Note that the equivalent of _ffdh_groups for ECDH is ec._CURVE_TYPES.)
